**Prediction models** in the left menu opens two tabs, **Summary** and **Models**. Each model then opens on its own
page with the tabs **Result**, **Properties**, **Events**, **Accuracy metrics**, and **Tasks**.

## Summary Tab

The **Summary** tab is the default view when you open Prediction models. It shows the state of every prediction
model of the tenant: refresh, accuracy, intents, alarms, profile coverage, and recent runs.

### Summary Cards

Four cards at the top of the page show the most important figures across all prediction models:

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/interface-summary-cards.webp',
    alt: 'Summary tab with the Auto refresh, Avg accuracy, Models by intent, and Alarms triggered cards marked 1 to 4',
    caption: 'Auto refresh (1), Avg accuracy (2), Models by intent (3), and Alarms triggered (4).',
  },
]} />

**Auto refresh** — how many models refresh on a schedule, out of all models, and every model by status:

| Metric | Meaning |
|--------|---------|
| **Total created** | All prediction models of the tenant |
| **Ready** | Models trained for every item |
| **Partially failed** | Models trained for some items and failed for others |
| **Failed** | Models that failed to train |

**Avg accuracy** — the average accuracy of all trained models, 100 minus sMAPE:

| Metric | Meaning |
|--------|---------|
| **Best model** | The highest accuracy of a single model |
| **Degraded (≥5%↓)** | Models that lost 5% or more accuracy against the previous 30 days |
| **vs last month** | The change of the average accuracy, last 30 days against the 30 days before |

**Models by intent** — how many models exist of each intent: **Forecast**, **Period Total**, **Time to Threshold**,
and **Hit Target**.

**Alarms triggered** — the ThingsBoard alarms raised by prediction models, by severity: **Critical**, **Major**,
**Minor**, and **Warning**.

### System Pulse

The **System pulse** panel on the right lists recent model runs, newest first, so you can see whether training and
refreshes succeed:

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/interface-summary-pulse.webp',
    alt: 'System pulse panel listing hourly refresh runs of Site energy monthly budget, each with 9 refreshed, 0 skipped, and 0 failed items',
    caption: 'Hourly refreshes of Site energy monthly budget: 9 items refreshed each time.',
  },
]} />

Each entry shows the model name, how long ago it ran, a tag for the kind of run, and its item counts:

| Tag | Run | Counts |
|-----|-----|--------|
| **Train** | Training | Items trained, failed |
| **Refresh** | Periodic refresh | Items refreshed, skipped, failed |
| **Accuracy** | Accuracy evaluation | Items trained, failed, or the run status |

The dot shows the run status: **Completed** (green), **Partial**, **Failed**, or **Canceled**.

## Models Tab

The **Models** tab lists all prediction models across all profiles in a single table. **+ Create model** in the
header opens the wizard.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/interface-models-tab.webp',
    alt: 'Prediction models page with the Models tab highlighted',
    caption: 'Models tab — the full list of prediction models.',
  },
]} />

Each row in the table shows:

| Column | Description |
|--------|-------------|
| **Name** | Model name and the profile it belongs to |
| **Created** | When the model was created |
| **Status** | **Ready**, **Training**, **Partially failed**, **Failed**, or **Cancelled** |
| **Intent** | **Forecast**, **Period Total**, **Time to Threshold**, or **Hit Target** |
| **Horizon** | How far ahead the model predicts, for example **Next 7 days** or **This Month** |
| **Auto-Refresh** | Whether periodic refresh is on |
| **Saving Telemetry** | Whether predictions are written to ThingsBoard |
| **Accuracy** | The accuracy of the model |
| **Entities** | Items in the model out of all items of the profile |

| Intent | Result tab shows | Described in |

### Item actions

The **⋯** button at the end of each item row opens the actions for that one item:

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/forecast-item-menu.webp',
    alt: 'Items table with the three-dot button at the end of a row highlighted',
    caption: 'Click <b>⋯</b> at the end of a row to open its actions.',
  },
]} />

| Action | What it does | When to use it |
|--------|--------------|----------------|
| **Refresh** | Fits the item's model on the readings that arrived since the last refresh and predicts again | The prediction is out of date and you do not want to wait for the next scheduled refresh |
| **Retrain** | Trains the item's model again from scratch on the whole training period | The item's behavior has changed, or its training failed |
| **Delete** | Removes the item and its predictions from the model. The device or asset in ThingsBoard stays as it is | The item should not be predicted, for example a test device or a closed site |

### Data status

The **Data status** card shows the selected item and how long ago it was last refreshed. Its buttons run the same
work as the row menu, for more items at once:

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/forecast-data-status.webp',
    alt: 'Result tab with the Data status card highlighted, showing the selected item, its last refresh, and the Refresh item, Refresh all, and Retrain all failed buttons',
    caption: 'Data status of the selected item, with buttons for one item or the whole model.',
  },
]} />

- **Refresh item** refreshes the selected item.
- **Refresh all** refreshes every item of the model.
- **Retrain all failed** trains again every item whose training failed.

### Tasks Tab

Trendz runs the work of a model as tasks. The **Tasks** tab lists the tasks of this model: one that trains it, and
one that refreshes it on a schedule once periodic refresh is on.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/interface-tab-tasks.webp',
    alt: 'Tasks tab listing two tasks: Prediction model, refresh, scheduled, saving the prediction model result to ThingsBoard, and Prediction model, create, run once, training the prediction model',
    caption: 'The training task and the scheduled refresh task of the model.',
  },
  {
    src: '/src/assets/images/trendz/prediction/interface-tasks-menu.webp',
    alt: 'Row menu of a task with the Details and Go to Task items',
    caption: 'The row menu: <b>Details</b> and <b>Go to Task</b>.',
  },
]} />

| Column | Description |
|--------|-------------|
| **Name** | The task and the model, for example *Prediction model, refresh: Site energy peak alert* |
| **Created** | When the task was created |
| **Updated** | When the task last changed |
| **Status** | The state of the task. **RUNNING** is highlighted |
| **Task type** | **Run Once** for training, **Scheduled** for the periodic refresh |
| **Job Type** | What the task does: **Train prediction model** or **Save prediction model result to TB** |

The row menu holds two actions:

- **Details** opens the executions of the task: start and finish time, duration, and status. Clicking the row does
  the same.
- **Go to Task** opens the task on the **Tasks** page in a new browser tab.

<Aside type="note">
The Tasks tab stays disabled until the model has at least one task.
</Aside>
