The model page shows one item at a time. To put predictions in a report or on a dashboard, use one of three
routes:

| Route | Shows | Needs |
|-------|-------|-------|
| **Model field in a Trendz view** | The forecast next to the history, for any item | Monitoring on the model |
| **Rule and target fields** | Time to event and % of target, the latest value | **Business entity field** on the rule or target |
| **Predicted telemetry in ThingsBoard** | The same results as ordinary ThingsBoard telemetry | **Save telemetry** on the model |

## Forecast on a Trendz chart

Every monitored prediction model adds a field to its business entity, named after the model. Put that field on a
chart, and Trendz draws the forecast after the measured values.

### Step 1. Create a line chart

On the Trendz home page, click **Create View** and choose **Line**.

### Step 2. Add the date and the model field

1. Drag **Date** to **X Axis**.
2. Open the business entity of the model, **Site Energy** in this example. The model fields are listed with the
   entity's telemetry, marked with a trend icon.
3. Drag the measured telemetry, `total`, and the model field, **Site energy peak alert**, to **Y Axis**.
4. Drag the entity itself, **Site Energy**, to **Filters** to choose the item.

### Step 3. Set the range, the item, and the grouping

- **Date range:** make it reach into the future, as far as the forecast goes. Here it runs from Sep 17 to Oct 1.
- **Filter:** pick one item, **site-energy-001**.
- **Group by:** match the model's grouping, **hour** for this model.

Click **Build report**. The measured values end at the latest sample, and the forecast continues as a dashed line.
Click the check mark, **Save changes**, to keep the view.

## Model field settings

Click the model field on **Y Axis** to open its settings.

| Setting | What it does |
|---------|--------------|
| **Telemetry source** | **Product** reads the forecast stored in Trendz. **Platform** reads the forecast saved to ThingsBoard, and works only when the model has **Save telemetry** on |
| **Prediction period settings** | Extends the view's date range forward by **Prediction range** and **Prediction unit**. They default to the model's horizon, 7 days here |

## Rule and target fields

A Time to Threshold rule or a Hit Target target can add its own field to the business entity. Turn on
**Business entity field** in the rule's or target's **Actions**.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/visualization-rule-field.webp',
    alt: 'Manage rules dialog of the Site energy peak alert model with the Business entity field switch highlighted under Actions',
    caption: 'Business entity field on a rule.',
  },
]} />

| Field | Value |
|-------|-------|
| **Time to event**, from a rule | Time left until the predicted crossing. `0` while the crossing is under way, `-1` when none is predicted |
| **% of target**, from a target | The predicted value as a share of the target. Blank before the first refresh |

These fields keep only the latest value, so use them in cards and tables rather than in charts over time. For a
history, set **Telemetry source** to **Platform**. The field then reads the series saved to ThingsBoard.

## Predicted telemetry in ThingsBoard

With **Save telemetry** on, a model writes its results to each item as telemetry. Use them in any ThingsBoard
widget.

| Key | Holds | Example from site-energy-001 |
|-----|-------|------------------------------|
| `_EPD_<key>` | The forecast series, one point per forecast step | `_EPD_site_energy_peak` = 543.6 |
| `_EPE_<key>` | Time to event of a rule, in milliseconds. `0` during the crossing, `-1` when none is predicted | `_EPE_peak_load_eta` = -1 |
| `_EPT_<key>` | % of target of a target, one point per day | `_EPT_monthly_budget` = 88.1 |

- **Forecast chart:** a time series widget on `_EPD_<key>`, with a time window that reaches into the future.
- **Countdown or progress card:** a latest value widget on `_EPE_<key>` or `_EPT_<key>`. Handle `-1` and `0` in
  the widget settings.

The keys are described in <DocLink product={props.product} path="prediction/monitoring#step-4-turn-on-save-telemetry">Save telemetry</DocLink>.

## Trendz views on ThingsBoard dashboards

A saved Trendz view can be placed on a ThingsBoard dashboard as a widget. The dashboard then shows the same
forecast chart. See <DocLink product={props.product} path="embed-visuals">Embed visuals</DocLink>.

## Which route to use

| Goal | Route |
|------|-------|
| A forecast chart in a Trendz report | Model field in a line chart, **Telemetry source** **Product** |
| A forecast on a dashboard without Trendz widgets | **Save telemetry**, then a time series widget on `_EPD_<key>` |
| A countdown or target card | Rule or target field, or a latest value widget on `_EPE_<key>` / `_EPT_<key>` |
| A countdown or target over time | Rule or target field with **Telemetry source** **Platform** |
| A fleet sorted by risk | The items table on the model page |
